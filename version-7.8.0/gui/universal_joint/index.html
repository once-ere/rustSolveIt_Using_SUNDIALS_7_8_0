Universal joint bearing —hinge— input shaft —universal— output shaft —rod— post, driven live by the pure-Rust SUNDIALS IDA solver — the page only draws what the solver returns

Model: HINGE 5 + UNIVERSAL 4 + ROD 1 = 10 rows on 12 freedoms. The UNIVERSAL holds one shared point and one right angle between the trunnion axes — it does NOT hold the shafts straight; the rod to the post bounds that freedom, so the bend runs from 0° to 53.130° (cos = 0.6) and no further. A constant torque spins the input up from rest. Watch the speed ratio: a Cardan joint is not constant-velocity — the ratio must live between cosβ and 1/cosβ for the current bend β.
