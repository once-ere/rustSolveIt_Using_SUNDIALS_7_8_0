A chain on ball joints

Four links hung on BALL joints. A ball joint holds one point and frees all three rotations, so unlike the hinged double pendulum this chain is not trapped in a plane. The start is a rigid rotation of the whole assembly about the vertical at 1.5 rad/s, which satisfies every joint exactly, so the run begins on the constraint manifold: |g| = 0 and |g_dot| = 0, both exactly, with no consistent-velocity projection. Give the identical start to the same chain built from HINGE joints and |g_dot| = 1.5 -- exactly the whirl rate, because the whirl is the one thing a hinge forbids. Watch the z axis: every link starts exactly on the plane z = 0 and the chain reaches |z| = 1.7147, where a hinge chain would still be at exactly zero. Measured over this recording: the four joints hold to |g| = 3.3e-9, and |dE|/E = 2.8e-4 across 250 separate IDA restarts, one per frame.
